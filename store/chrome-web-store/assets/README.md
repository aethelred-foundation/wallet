# Chrome Web Store Visual Assets — Specification

This directory is where the Aethelred Wallet design team drops the
visual assets the Chrome Web Store listing requires. **No PNGs are
generated by this repository's build pipeline** — every asset is a
design deliverable. The file list below is a checklist so design
knows exactly what to produce, and so engineering can verify every
slot is filled before submission.

Every asset below must:

- be PNG (no JPEGs, no WEBP — Chrome only accepts PNG for listing
  assets as of 2026);
- have the EXACT pixel dimensions listed; Chrome rejects assets
  that deviate by a single pixel;
- contain no copyright-encumbered fonts, icons, or imagery;
- contain no "Store exclusive", "Alpha", or "Beta" chrome unless the
  extension version is genuinely labeled as such.

File names below are canonical — the submission script expects them in
this directory.

## Required — Store listing assets

| Slot | File | Dimensions | Notes |
|---|---|---|---|
| Small promo / store icon | `store-icon-128.png` | 128 x 128 | Master icon displayed in the Web Store header and in the Chrome extensions list. Must have transparent background. |
| Small promo tile | `promo-tile-440x280.png` | 440 x 280 | Shown on the Web Store category pages. Composition: Aethelred mark on left 40%, one-line tagline on right 60%. Use brand gradient bg. |
| Marquee promo tile | `promo-marquee-1400x560.png` | 1400 x 560 | Reserved for featured placement. Used only if we are approved for the Featured shelf. |
| Large promo tile | `promo-large-920x680.png` | 920 x 680 | Shown on dedicated promo placements. Same composition as the marquee at a squarer aspect. |

## Required — Screenshots (minimum 1, maximum 5)

| Slot | File | Dimensions | Caption |

Chrome also accepts 640 x 400 as a fallback size; use 1280 x 800 for
crispness on modern displays.

## Internationalization

Each screenshot file should be delivered with English locale text
baked in. Localized versions (if/when we translate the store listing)
go under `assets/<locale>/` in the same file-name structure.

## Legal / brand review gate

Every asset delivered here MUST carry a `REVIEWED_BY` comment in the
design ticket:

```
REVIEWED_BY: <brand-reviewer>, <legal-reviewer>, YYYY-MM-DD
```

The submission checklist (`../CHECKLIST.md`) will not pass until every
asset in this directory has a paired design-ticket review record.
